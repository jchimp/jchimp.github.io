How a token hunts for context

Attention is the mechanism. Each token asks a question, every other token answers, and the strongest answers get pulled in. That's the "hunt."

map One forward pass, top to bottom

A token's vector flows up a tall stack of identical layers. Two moves alternate: attention mixes information between tokens, then an MLP transforms it at each token. Repeat dozens of times.

attention The three vectors every token computes

Inside an attention layer, three small weight matrices turn each token's vector into three new ones. The names are jargon; the roles are simple.

Query (Q)
"What am I looking for?"
Key (K)
"What do I offer / what am I about?"
Value (V)
"The info I'll actually hand over."

The hunt: take one token's Query and dot-product it against every Key in the context. High score = high relevance. Softmax turns the scores into weights that sum to 1, and the token's output is the weighted sum of all the Values — mostly grabbing from whatever scored highest.

Causal mask — only look back

When generating, a token may attend to itself and earlier tokens only, never future ones — you can't read words you haven't written. Side effect: a past token's K and V never change, so you cache them. That cache is the KV cache from the inner loop.

Multi-head — many lenses at once

It isn't one Q/K/V comparison but many in parallel, each with its own learned matrices. One head may track grammar, another what a pronoun refers to, another the topic 1,000 tokens back. They run together and combine — many kinds of relevance, simultaneously.

Why this is the whole reason context works

Attention lets any token pull directly from any other token in the window, in one step, no matter how far apart. That's how the model links a pronoun to a noun, uses a fact from the system prompt, or reads a tool result you injected — all the same gather.

The context window is just how many tokens can sit in this comparison at once. "Running out of context" = the hunt can't reach past the edge. Cost grows with the square of length, which is why bigger windows are hard.

And "reasoning"? Stack this gather-and-transform dozens of layers deep, then have the model generate its own intermediate tokens first — each new thinking token becomes more context the next hunt can attend to. Reasoning is the model building its own trail of breadcrumbs to attend back to.
