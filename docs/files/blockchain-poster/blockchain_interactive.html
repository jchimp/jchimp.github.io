How a Blockchain Works

The arithmetic that makes a shared record practically impossible to rewrite. Bitcoin is the example. Everything below is live — type into it, break it, and re-mine it.

The Hash

a one-way fingerprint for any data

A hash function takes any input and returns a fixed 64-character fingerprint. Bitcoin uses SHA-256. Same input always gives the same output, you can't run it backwards, and changing one character scrambles the whole thing. Type below — this is real SHA-256, computed in your browser.

The Chain

each block is built from the one before it

Each block records the previous block's hash in its prev field — that copy is the chain. The toy hash below is small on purpose so you can check it by hand: hash = ( data + prev + nonce ) × 137, keep the last 4 digits. Edit any data field and watch the chain react.

Hover a block to see which earlier hash its prev was copied from. Change a data value: that block's hash changes, so every later prev stops matching and the chain turns red.

Proof of Work

why a valid hash has to start with zeros

Miners don't choose the hash, they search for it: change the throwaway nonce and re-hash until the result clears a target. Our target is a number of leading zeros. More zeros = exponentially rarer = more work. Drag the difficulty and re-mine the chain to feel it.

Drag difficulty up, then press “Re-mine whole chain”. Each line is one rejected guess until a hash clears the target.
In real Bitcoin

Same idea, vastly harder. The target demands roughly 19 leading zeros, found only by the entire network making on the order of 100,000,000,000,000,000,000 guesses per block.

Even 4 leading zeros on a real SHA-256 took 7,370 tries here: 0000f8f8 9f1b8043 …

The wasted effort is the security. Redoing it for every block is what an attacker can't afford.

Transactions & Ownership

what is actually being chained

A coin isn't a balance in an account — it's an unspent output of an earlier transaction (a UTXO). To pay someone you consume past outputs and create new ones, each sealed to the next owner. So every coin carries an unbroken chain of custody. Click any coin to trace its lineage back to where it was minted.

Ownership — digital signatures

Each output is locked to an owner's public key (their address). To spend it, the owner attaches a signature made with their secret private key; anyone can verify it with the public key, but no one can forge it or work back to the secret.

This — not the block chain — is where prime numbers actually do the work: the signatures use elliptic-curve math over a prime field. Mining is brute-force hashing, not prime-finding.
