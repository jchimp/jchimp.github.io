02 Which Tool?

Three ways to package repeated work.

Reuse the same prompt, maybe with an arg?
→ slash command
.claude/commands/<name>.md
A real procedure — logic, inputs, helper files?
→ skill
.claude/skills/<name>/SKILL.md
Needs its own context so it won't flood the thread?
→ subagent
.claude/agents/<name>.md

command = saved prompt
skill = saved procedure
subagent = saved worker w/ its own brain-space

03 Model Routing

Default down, escalate on purpose.

sonnetDefault · ~90%. The workhorse.
opusWalls. Architecture, subtle bugs, multi-input synthesis.
haikuMechanical. Bulk renames, formatting, speed.
opusplanOpus plans, Sonnet builds. Good session default.
Four control points
  • Live · /model opus
  • Launch · claude --model sonnet
  • Default · model in settings.json
  • Per-agent · model: in frontmatter

The one habit
If you typed it twice, put it in a file.

A CLAUDE.md line, a /command, a skill, or a subagent. That reflex — not any single feature — is what separates using Claude Code from operating it.
