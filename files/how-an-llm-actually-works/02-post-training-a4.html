Teaching a predictor to be an assistant

Pretraining loads knowledge. Post-training installs behavior — using the same gradient descent, but new data and a borrowed objective: human (and AI) judgment.

map The post-training pipeline
Base modela document completer — fluent, knowledgeable, but not yet "an assistant"
1 · Supervised fine-tuning (SFT)imitate thousands of written demonstrations of good assistant answers
2 · Reward modellearn a scorer of "how good is this answer?" from ranked preferences
3 · RL (RLHF + Constitutional AI)push the model to generate answers the scorer rates highly
4 · Reasoning RLreward chains of thought that reach verifiably correct answers
→ Aligned model → evals (A5) → frozen (A6)behavior now baked into the weights

stage 2–3 You can't code "good" — so learn it

There's no formula for "helpful." The workaround: have people rank model answers, train a reward model to predict those preferences, then use it as the objective for reinforcement learning.

⟳ the RLHF loop
① Policy generatesthe assistant model produces a few candidate answers
② Reward model scoresthe learned scorer rates each one — standing in for a human judge
③ Update the policygradient step that makes high-scoring answers more likely
↻ repeat millions of times
The leash: a penalty keeps the policy close to the SFT model, so it can't "reward-hack" into weird text that games the scorer but reads as nonsense.
Anthropic Constitutional AI — write the values down

Asking humans to label harmful content at scale is slow and grim. Constitutional AI replaces much of it with an explicit written constitution and lets the model supply its own feedback against it.

constitution — a set of plain-language principles (e.g. "choose the response that is most helpful and honest while least likely to be harmful"). Transparent and editable, instead of buried in crowd labels.

Phase A · critique & revise (supervised)

draft answer → critique it vs a principle → rewrite → train on the rewrite

Phase B · RL from AI feedback (RLAIF)

model compares two answers vs the constitution → that becomes preference data → trains the reward model → RL as above

Net effect: the AI helps judge harmlessness, guided by stated rules — so oversight scales, and the governing values are something you can read.

stage 4 Where the breadcrumbs get trained in

For tasks with a checkable answer (math, code), you don't need human preference at all. Let the model write a long chain of thought, then automatically verify the result and reward the chains that land correctly. It learns that thinking first pays off.

◇ reward from a verifier, not a human
user: what's 17 × 24? think: 17 × 24 = 17 × 25 − 17 = 425 − 17 = 408 answer: 408
✓ verifier: 408 correct → reinforce this chain

Crucially, the reward is on the outcome, so the model is free to discover which steps help — and it converges on writing them out. Each step it emits becomes context the next forward pass can attend back to. This stage trains the habit; attention + RoPE are what use it.

The whole map, in one line

Pretraining presses knowledge into the weights; post-training presses in behavior — and behavior is learned by borrowing an objective the model could never be handed directly: judgment, first human, then AI-against-a-constitution, then an automatic verifier.

After this, the weights freeze (A6) and the whole serving stack — harness loop, token loop, attention, position — runs on a model that has been taught not just what words come next, but how to be useful, careful, and deliberate while choosing them.
